What are Skill Swap Chains?
A Skill Swap Chain is a cycle where each person teaches one person and learns from another — no one needs to have the same skill. Instead of one-to-one swaps, chains unlock multi-person skill exchanges across the campus.
✓ Fair — everyone contributes
✓ Efficient — no skill needed in common

⚙️ How the Chain Algorithm Works

1. Build a directed graph — Each student is a node. A directed edge A→B exists if A offers a skill that B wants.

2. Find all simple cycles — Using depth-first search (DFS), we detect cycles of length 3 to 5 in the graph.

3. Deduplicate — Canonical forms prevent showing the same cycle multiple times rotated.

4. Rank by length — Shorter chains are shown first (3-person chains are the most practical).
